## Important
- The notebooks are intentionally self-contained where possible. Most datasets are loaded from `seaborn` or `scikit-learn`, so no CSV files are required for the first run.
- The ANN notebook uses TensorFlow/Keras and follows the class concepts of weighted inputs, nonlinear activation, loss and gradient-based training.
- For your final submission, run every notebook from top to bottom in Google Colab, check the outputs, and export the final notebooks/PDFs.
- Do not claim a score before actually running the notebook. Report the metrics produced by your run.
